# Create API Overview

Generate an API overview annotation on the Figma canvas for the selected component: a property table (values, defaults, required), sub-component tables, and configuration examples with live preview instances.

## Usage

```
/create-api
```

## What this command does

Read and follow `skills/create-api/SKILL.md` in this repo **in full, exactly as written**. Do not summarize or paraphrase that file — load it and execute its instructions directly against the component, component set, or instance currently selected on the Figma canvas.

If nothing eligible is selected, ask the user to select a component, component set, or instance first.
