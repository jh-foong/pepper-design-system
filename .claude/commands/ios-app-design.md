# iOS App Design

Designs and updates production-quality iOS mobile app screens and flows in an existing Figma file, preserving the product's existing design system, neighboring screens, Apple Human Interface Guidelines, accessibility, content rules, interaction patterns, and implementation feasibility.

## Usage

```
/ios-app-design [what to design]
```

## What this command does

Read and follow `skills/ios-app-design/SKILL.md` in this repo **in full, exactly as written**, applied to what the user describes (`$ARGUMENTS`). Do not summarize or paraphrase that file — load it and execute its instructions directly, including forming the Screen Contract, completing full design-system + reference-screen discovery before drawing anything, modeling information/action hierarchy and the state matrix, and running the full visual/structural/experience QA passes before presenting the result as final.

Note: this skill's own companion-skill references (`figma-use`, `figma-generate-design`, `figma-generate-library`) are from a different Figma-plugin tool ecosystem than the Figma MCP tools actually available in this session — adapt those references to the real available Figma tools rather than trying to load skills that don't exist here.
