# Layer Cleanup

Cleans up a messy Figma file — renames layers semantically, removes hidden junk, groups logically, and normalizes structure.

## Usage

```
/layer-cleanup
```

Select the frame to clean up first (or run on the current page if nothing is selected).

## What this command does

Read and follow `skills/layer-cleanup/SKILL.md` in this repo **in full, exactly as written**, applied to the user's current Figma selection or page (or the arguments given as `$ARGUMENTS`, if any). Do not summarize or paraphrase that file — load it and execute its instructions directly: audit and report counts first, rename semantically per the naming rules, do structural cleanup, and finish with a before/after summary. Never delete hidden layers without listing them and asking first, and never detach or restructure component instances.
