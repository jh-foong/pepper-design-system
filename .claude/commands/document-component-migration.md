# Document Component Migration

Compare a legacy and new component side-by-side, documenting what's new (with rationale), a property comparison table, annotated visual/structural differences on the new component, and deprecation notes.

## Usage

```
/document-component-migration
```

Select both the legacy and the new component sets in Figma first, then run this command.

## What this command does

Read and follow `skills/document-component-migration/SKILL.md` in this repo **in full, exactly as written**, applied to the user's current Figma selection (or the arguments given as `$ARGUMENTS`, if any). Do not summarize or paraphrase that file — load it and execute its instructions directly, including asking which selected component is the new version, asking the deprecation timeline, and building the full output structure (What's New, Property Comparison Table, Visual & Structural Differences with annotations, Deprecation Notes).
