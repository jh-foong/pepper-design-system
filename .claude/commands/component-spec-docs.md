# Component Spec Docs

Generate designer-facing component spec docs and build them on the canvas as a complete documentation frame: what each component is for, every variant and when to use it, the property API, dos and don'ts, and accessibility considerations, with live component previews.

## Usage

```
/component-spec-docs
```

Select or name the component(s) to document, then run this command.

## What this command does

Read and follow `skills/component-spec-docs/SKILL.md` in this repo **in full, exactly as written**, applied to the user's current Figma selection or named components (or the arguments given as `$ARGUMENTS`, if any). Do not summarize or paraphrase that file — load it and execute its instructions directly, including the 9-section per-component structure, the group-level "choosing between them" table, the exact-naming rule (never silently correct a typo in the file), and the `[assumed]` / `[needs confirmation]` flagging rule.
