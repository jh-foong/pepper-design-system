# Create Color Annotation

Generate a color annotation on the Figma canvas for the selected component: tables mapping every visual element to its design token, with live previews per variant or state.

## Usage

```
/create-color
```

## What this command does

Read and follow `skills/create-color/SKILL.md` in this repo **in full, exactly as written**. Do not summarize or paraphrase that file — load it and execute its instructions directly against the component, component set, or instance currently selected on the Figma canvas.

If nothing eligible is selected, ask the user to select a component, component set, or instance first.
