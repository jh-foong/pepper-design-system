# Create Property Annotation

Generate a visual property annotation on the Figma canvas for the currently selected component: one exhibit per variant axis, boolean toggle, variable-mode collection, and sub-component property, with live component-instance previews and a summary table.

## Usage

```
/create-property
```

## What this command does

Read and follow `skills/create-property/SKILL.md` in this repo **in full, exactly as written**. Do not summarize or paraphrase that file — load it and execute its instructions directly against the component, component set, or instance currently selected on the Figma canvas (or named in the request).

If nothing eligible is selected, ask the user to select a component, component set, or instance first, or name the component in the request.
