# Create Anatomy Annotation

Generate a visual anatomy annotation on the Figma canvas for the currently selected component: a composition section with numbered markers over a live component instance and a 4-column attribute table, plus per-sub-component sections showing internal elements (including hidden ones).

## Usage

```
/create-anatomy
```

## What this command does

Read and follow `skills/create-anatomy/SKILL.md` in this repo **in full, exactly as written**. Do not summarize or paraphrase that file — load it and execute its instructions directly against the component, component set, or instance currently selected on the Figma canvas.

If nothing eligible is selected, ask the user to select a component, component set, or instance first.
